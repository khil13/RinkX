# 08 · Development Roadmap

Each phase ends with a **test gate**. The next phase starts only when the gate passes, and the results are recorded in the PR for that phase.

| Phase | Scope | Deliverables | Test gate |
|---|---|---|---|

## Decisions needed from the product owner

Decided:
* **Personal use**, single owner, no redistribution.
* **Hosting on GitHub only**: Actions + Pages, with an encrypted SQLite store and an encrypted site (see `01-architecture.md` §0 and §5).
* **Jurisdiction and books:** New Jersey; FanDuel and BetMGM (`config/books.yml`).
* **Odds feed:** The Odds API (Phase 4), free tier to start. The game model (win, shutout, first goal, totals) shipped first, as model 1.1.

Still open:

1. **Odds plan size.** Phase 4 is built for The Odds API, starting on the free tier (500 credits a month, about 1–2 games of props a day). Upgrade and raise `config/budget.yml: monthly_credits` to cover every game.
2. **Lineup / goalie / injury feed.** Phase 3 ships the free default: projected starters from recent starts, plus Quick Entry confirmations. A paid personal-tier feed is optional.
3. **Setup you'll do once:** see [`setup.md`](setup.md). Enable Pages, run the pipeline, generate keys on the Setup page, add `DATA_KEY` and `STORE_KEY` as secrets, and commit the keyfile. Later: `ODDS_API_KEY`, `NTFY_TOPIC`.
